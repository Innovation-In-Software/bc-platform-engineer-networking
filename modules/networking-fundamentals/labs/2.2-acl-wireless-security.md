## Step 6. Write and Apply the Extended ACL

### Create the ACL on Router0

Click **Router0** → **CLI** tab.

```
Router0> enable
Router0# configure terminal
Router0(config)# ip access-list extended BLOCK_TELNET
Router0(config-ext-nacl)# deny tcp 192.168.20.0 0.0.0.255 192.168.10.0 0.0.0.255 eq 23
Router0(config-ext-nacl)# permit ip any any
Router0(config-ext-nacl)# exit
```

> **Why `permit ip any any`?**  
> Cisco ACLs have an implicit `deny all` at the end. Without this permit statement, the ACL would block all traffic — not just Telnet. The explicit permit ensures only TCP port 23 is denied.

### Apply the ACL inbound on the VLAN 20 subinterface

```
Router0(config)# interface g0/0/0.20
Router0(config-subif)# ip access-group BLOCK_TELNET in
Router0(config-subif)# exit
```

> **Why inbound on G0/0/0.20?**  
> Applying the ACL *inbound* on the VLAN 20 subinterface catches traffic from PC1 the moment it enters the router — before it can reach VLAN 10. This is more efficient than applying it outbound on G0/0/0.10.

## Step 10. Compare WEP vs WPA2

### Switch to WEP and observe the warning

1. Click **WRT300N** → **GUI** → **Wireless** → **Wireless Security**
2. Change Security Mode to **WEP**
3. Click **Save Settings**
4. Note the security warning Packet Tracer displays — record this for your report

### Why is WEP unsafe?

| Feature | WEP | WPA2 |
|---------|-----|------|
| Encryption | RC4 (stream cipher) | AES (block cipher) |
| Key management | Static — never changes | Dynamic per-session keys (CCMP) |
| Initialization Vector (IV) | 24-bit, sent in plaintext | 48-bit, encrypted |
| Vulnerability | IV repeats under normal traffic; key crackable in minutes | No known practical attack |
| Status | Deprecated since 2004 (IEEE 802.11i) | Current minimum standard |

> WEP's 24-bit IV space exhausts quickly under normal traffic volume. An attacker capturing approximately 50,000 packets can use statistical analysis to recover the key — tools like Aircrack-ng automate this in minutes. WPA2 uses AES-CCMP with per-session dynamic keys, eliminating this attack surface entirely.

### Revert to WPA2 before submitting

1. **WRT300N** → **GUI** → **Wireless** → **Wireless Security**
2. Set Security Mode back to **WPA2 Personal**, re-enter passphrase
3. Click **Save Settings**
4. Reconnect Laptop0 via **PC Wireless** if it dropped

---

## Summary

| Concept | Description |
|---------|-------------|
| Extended ACL | Filters on source, destination, protocol, and port number |
| ACL direction | Inbound = filter before routing; outbound = filter after routing |
| dot1Q encapsulation | Tags frames so the router knows which VLAN they belong to |
| WEP | Deprecated RC4-based wireless security; crackable in minutes |
| WPA2-PSK | AES-CCMP encryption with dynamic keys; current minimum standard |
| ROAS | Router-on-a-Stick: one physical interface handles multiple VLANs via subinterfaces |
