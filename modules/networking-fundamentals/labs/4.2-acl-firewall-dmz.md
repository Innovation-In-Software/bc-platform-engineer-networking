# Lab 09 – ACL-Based Firewall Rules & DMZ Design

**Objective:**  
Use extended ACLs on a Cisco router to replicate basic firewall behaviour across three network zones — Outside (internet), DMZ (public-facing server), and Inside (internal LAN). You will observe traffic flows before any ACLs are applied, then build and apply rules zone by zone, testing each change as you go.

## Step 2. ACL 110 — Control Traffic Entering from Outside

We apply this ACL **inbound on Gi0/0** (the Outside/internet interface). This controls what the internet is allowed to send into our network.

### Policy being enforced:
- Internet → DMZ port 80: **permit** (public web access)
- Internet → Inside: **deny** (internal network must stay private)
- Internet → anything else: **permit** (for now — we will tighten this later)

### Write and apply ACL 110
```
Router0(config)# access-list 110 remark Allow internet to reach DMZ web server on port 80
Router0(config)# access-list 110 permit tcp any host 10.0.2.10 eq 80

Router0(config)# access-list 110 remark Block internet from reaching internal LAN
Router0(config)# access-list 110 deny ip any 10.0.1.0 0.0.0.255

Router0(config)# access-list 110 remark Permit all other traffic (can be tightened later)
Router0(config)# access-list 110 permit ip any any

Router0(config)# interface GigabitEthernet0/0
Router0(config-if)# ip access-group 110 in
Router0(config-if)# exit
```

> **Placement rule:** Extended ACLs go as close to the **source** as possible to stop traffic early and save bandwidth. Here the source of internet traffic is the Outside interface, so we apply inbound there.

### Test ACL 110
Ping from Outside PC:
```
C:\> ping 10.0.2.10     (DMZ)    -- should still succeed (ICMP is permitted by last line)
C:\> ping 10.0.1.10     (Inside) -- should now FAIL (blocked by deny)
```

> **Why does ping to DMZ still work?** The first rule only permits TCP port 80 — but the last `permit ip any any` allows ICMP. In a real firewall you would remove that catch-all and only permit specific traffic.

Check match counters:
```
Router0# show access-lists 110
```

**Expected output:**
```

    10 permit tcp any host 10.0.2.10 eq www (X matches)
    20 deny ip any 10.0.1.0 0.0.0.255 (X matches)
    30 permit ip any any (X matches)
```

## Step 3. ACL 111 — Prevent DMZ from Attacking Inside

A compromised DMZ server should not be able to attack the internal LAN. We apply this ACL **inbound on Gi0/1** (the DMZ interface).

### Policy being enforced:
- DMZ → Inside: **deny**
- DMZ → anywhere else: **permit**

### Write and apply ACL 111
```
Router0(config)# access-list 111 remark Block DMZ from reaching internal LAN
Router0(config)# access-list 111 deny ip 10.0.2.0 0.0.0.255 10.0.1.0 0.0.0.255

Router0(config)# access-list 111 remark Permit DMZ to reach the internet
Router0(config)# access-list 111 permit ip any any

Router0(config)# interface GigabitEthernet0/1
Router0(config-if)# ip access-group 111 in
Router0(config-if)# exit
```

### Test ACL 111
Ping from DMZ PC:
```
C:\> ping 10.0.1.10     (Inside) -- should now FAIL
C:\> ping 203.0.113.2   (Outside) -- should still succeed
```

Check match counters:
```

```

## Step 5. Tighten the Outside ACL (Challenge)

The current ACL 110 has a catch-all `permit ip any any` at the end, which allows all non-blocked traffic from the internet. In a real firewall, you would remove this and only permit specific traffic.

### Rewrite ACL 110 — remove the catch-all
```
Router0(config)# no access-list 110

Router0(config)# access-list 110 permit tcp any host 10.0.2.10 eq 80
Router0(config)# access-list 110 permit tcp any host 10.0.2.10 eq 443
Router0(config)# access-list 110 deny ip any 10.0.1.0 0.0.0.255
Router0(config)# access-list 110 deny ip any 10.0.2.0 0.0.0.255
Router0(config)# access-list 110 permit ip any any

Router0(config)# interface GigabitEthernet0/0
Router0(config-if)# ip access-group 110 in
Router0(config-if)# exit
```

> **Note:** The implicit `deny any` at the end of every ACL now blocks all unmatched internet traffic. Outside PC will no longer be able to ping the DMZ (ICMP is not permitted) — only TCP port 80 and 443 are allowed in.

## Summary

| ACL | Applied On | Direction | Purpose |
|-----|-----------|-----------|---------|
| 110 | Gi0/0 (Outside) | Inbound | Permit internet→DMZ:80, block internet→Inside |
| 111 | Gi0/1 (DMZ) | Inbound | Block DMZ→Inside (contain compromised server) |

| Key Command | Purpose |
|-------------|---------|
| `access-list 110 permit tcp any host X.X.X.X eq 80` | Permit specific TCP port to a host |
| `access-list 110 deny ip any 10.0.1.0 0.0.0.255` | Block entire subnet |
| `ip access-group 110 in` | Apply ACL inbound on interface |
| `show access-lists` | View rules and match counters |
| `show ip interface Gi0/0` | Confirm which ACL is applied |
